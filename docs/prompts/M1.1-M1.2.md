## Scope

   by all dependencies; report it (open decision O4).

   constraint naming convention.
8. Alembic: URL read from settings (not alembic.ini), env.py uses Base.metadata, plus ONE empty baseline revision. No business tables.
9. Logging must never print the database URL or password.
10. README with exact local run steps.
